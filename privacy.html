Privacy Policy

Last updated: 22 November 2026

1. Use of YouTube API Services

yt-shorts-auto uses YouTube API Services (YouTube Data API v3) to upload videos to the developer's own YouTube channel. By using this app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

2. What data is accessed, collected, stored and shared

  • Accessed: only the youtube.upload permission, used solely to call videos.insert and upload videos with their title, description and tags. The app does not read channel data, comments, analytics, subscribers or any other user data.
  • Stored: the OAuth client credentials and a refresh token are stored only in the owner's own environment (a local file and encrypted GitHub Actions secrets). The YouTube video ID returned after each upload is stored in the owner's private repository as a publishing record.
  • Collected about other people: none. The app has a single user (its owner).
  • Shared: no data is sold, shared with, or transferred to any third party.
  • Cookies / tracking: this website and the app use no cookies, analytics or tracking technologies, and no device information is collected.

3. Revoking access and deleting data

Access can be revoked at any time via the Google security settings page. After revocation the stored refresh token stops working and is deleted from the owner's environment. Stored API data (video IDs) can be deleted on request; any stored API data is deleted within 7 days of revocation or of a deletion request, and is never kept longer than 30 days without being refreshed, as required by the YouTube API Services Developer Policies.
