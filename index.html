What is this app?

yt-shorts-auto is a personal, single-user tool that renders short vertical educational videos (computer science concepts, in Turkish) and uploads them to the developer's own YouTube channel using the YouTube Data API (YouTube API Services). It is operated only by its owner; it has no public user interface and does not serve other users.

  • API used: YouTube Data API v3, endpoint videos.insert only.
  • OAuth scope: https://www.googleapis.com/auth/youtube.upload
  • Runs once per day as a scheduled job (about 1 upload per day).

Bu uygulama nedir?

yt-shorts-auto, bilgisayar bilimi kavramlarını anlatan kısa dikey videoları otomatik üreten ve geliştiricinin kendi YouTube kanalına YouTube Data API (YouTube API Servisleri) ile yükleyen kişisel bir araçtır. Yalnızca sahibi tarafından kullanılır; başka kullanıcılara hizmet vermez.
